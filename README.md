# Dhiya Labs — website (Astro)

Static Astro 5 site with one server route for the contact forms. Built for Vercel; any adapter works.

## Run
```
npm install
npm run dev        # http://localhost:4321
npm run build      # dist/
```

## Where things live
- `src/pages/index.astro` — homepage, assembled from `src/components/home/*` (hero video stage, five lines, kilowatts break, chaos→calm bento, the DIL heart, architecture, use cases) + the shared CTA/form.
- `src/pages/[slug].astro` + `src/components/ProductPage.astro` — DIL, Ayana, Neev, Vitana, Aire. **All copy for these pages is data:** `src/data/products.ts` (hero, steps, mock-ups, "what makes it different", integrations, CTA).
- `src/pages/about.astro` — About + investor block.
- `src/pages/privacy.astro`, `terms.astro`, `security.astro` + `src/components/LegalPage.astro` — legal pages. Copy is in `src/data/legal.ts`; company name, address, jurisdiction and last-updated date are in `site.legal` (`src/data/site.ts`).
- `src/components/ContactForm.astro` — the basic-details form. `kind="partner"` → hi@dhiya.ai, `kind="investor"` → founders@dhiya.ai (addresses in `src/data/site.ts`).
- `src/pages/api/contact.ts` — receives the form (JSON), sends via Resend when `RESEND_API_KEY` is set, otherwise logs. Verify `dhiya.ai` in Resend and set `MAIL_FROM`.
- `public/iso.js` — the isometric hero scenes (pure SVG, brand colours from CSS vars). `public/forms.js` — form handling with a mailto fallback when no endpoint is set.
- `src/styles/global.css` (tokens, nav, footer, product pages, forms) and `src/styles/home.css` (homepage only).
- `public/media` — video, stills, logos, OG image. `public/llms.txt`, `public/robots.txt`. Sitemap is generated by `@astrojs/sitemap` at `/sitemap-index.xml`.

## Deploy (Vercel)
Import the repo, framework = Astro, add `RESEND_API_KEY` (and `MAIL_FROM`) in Project → Environment Variables. The API route runs as a serverless function; everything else is static.

## Diwali inauguration
- The homepage shows the launch introduction for its first 10 appearances in the same browser profile and origin. Reloading counts as another appearance; cutting, skipping or pressing Escape does not increment it again. The count persists in localStorage (`dhiya:diwali-launch:2026:v1`). Clearing site storage resets it. If localStorage is blocked, sessionStorage is used; if neither works, the website opens normally.
- Press Enter or click the ghee-gold ribbon to open Dhiya. A compact plum panel sits over Dhiya's plum, lilac and blue light bands. Cutting the ribbon reveals a gold “Welcome to Dhiya” before the bands dissolve into the homepage. **Skip intro** and Escape skip the animation. Reduced-motion preferences show a brief static welcome.
- During local development, `/?launch-preview=1` previews the ceremony without consuming an appearance. This override is disabled in production builds.
- The small lamp in the announcement ribbon lights the Diwali lamps for six seconds. The normal design-partner link remains separate.

## Conventions
- Racks are 52U. Figures are USD. No case studies, no "watch the film".
- Product accents: Ayana Ember `#B03729`, Neev Engine cyan `#3EC6E8`, Vitana Hyperspace `#315ADE`, Aire Sky `#6CA9CB`; page tints are each accent's lightest shade. Brand lilac `#9B5DE5`, ink `#221A21`, page `#EAE0F0`.
